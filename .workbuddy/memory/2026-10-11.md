## 环境注意事项（重要）

- 本机 bash 工具基本不可用：shell 包装脚本报 dirname: command not found，ls/find/head 等外部命令全部失效。仅当命令使用**绝对路径调用 python 等可执行文件**时才能正常执行；纯 shell 工具链不要指望。日常文件操作请优先用 PowerShell 工具。
- PowerShell 工具的 stdout **不会**被返回（永远只有 Command completed with exit code 0）。绕法：把结果 Set-Content 写入临时文件，再用 Read 工具读取。
- PowerShell 的 Remove-Item 删目录会触发 [safe-delete][SAFE_DELETE_FAIL_CLOSED] 护栏（genie-trash 失败即拒绝）。空目录也可能删不掉，属正常现象，不影响文件移动结果。删文件（非目录）一般都成功。
- Write / Edit 工具写入 C:\Users\ROG\Downloads\android2\android2\.workbuddy\ 下的文件时，实际落盘位置与预期不一致，Glob/Read 查不到。需要持久化本目录下的文件时，**改用 PowerShell 写入**。
- JAVA_HOME 未设置；java 在 PATH 上（Oracle javapath）。未验证 gradlew 能否正常构建。

## editor_sdk 使用要点（踩坑记录）

- 工具入口：D:\worlbuddy\WorkBuddy\resources\app.asar.unpacked\resources\plugins\workbuddy-builtin\skills\tencent-local-office-edit\edsdk.py，用绝对路径的 python 调用。
- 流程：present_files 呈现文档 → get_pool_status 按 file_path 取 UUID file_id → doc_* 编辑 → save_file（不要主动 close_file）。
- doc_replace_text **不能跨段落分隔符**，删整段必须用 doc_delete_paragraph；批量删空格从后往前逐次调用。
- 插入长内容用 doc_insert_markdown，markdown 参数可传 "file://<绝对路径>" 从文件读，避免超长命令行。
- 多余位置：ins 用 doc_resolve_document_structure 的 start_index（空段落占 1 个 code unit）。
- 同时处理多处时，先改靠后的位置，避免索引偏移。
